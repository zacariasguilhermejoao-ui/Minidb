# MiniDB Android

Aplicação Android desenvolvida em Kotlin.

## Compilação do APK
O projeto está preparado para compilar com Java 17 e Gradle 8.9 através do GitHub Actions. Depois de adicionar os ficheiros do projeto e o workflow em `.github/workflows/build.yml`, abra o separador **Actions**, selecione o workflow e descarregue o artefacto `app-debug-apk` quando a compilação terminar.
